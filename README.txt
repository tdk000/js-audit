JsAudit — аудит JS-движков на компьютере (портативная версия)
===============================================================

Что делает
----------
Находит все приложения, внутри которых работает JavaScript:
Electron (app.asar), CEF, WebView2, вшитый Chromium, Node.js,
браузеры, системный JScript (WSH/MSHTA). Считает живые JS-процессы,
проверяет политики WebView2/Edge в реестре.

Результат — HTML-отчёт с гистограммами + CSV + JSON.
В самом отчёте ни одной строки JavaScript (только HTML и CSS).

Как запустить
-------------
1. Скопировать папку целиком (3 файла + README) на флешку или другой ПК.
2. Дважды кликнуть JsAudit.cmd.
3. Ждать 1–3 минуты. Отчёт откроется в браузере сам.

Права администратора не нужны. Устанавливать ничего не нужно —
используется встроенный PowerShell (есть на любом Windows 10/11).

Куда падают отчёты
------------------
- По умолчанию: папка out\ рядом со скриптом.
- Если носитель только для чтения: %TEMP%\JsAudit_<имя ПК>_<дата>.
- Каждый отчёт подписан именем компьютера и датой — можно гонять
  по нескольким машинам и собирать отчёты в одну папку.

Полезные ключи
--------------
JsAudit.cmd -NoOpen          не открывать браузер после прогона
JsAudit.cmd -OutDir "C:\R"   класть отчёты в указанную папку

Если SmartScreen ругается
-------------------------
«Подробнее» → «Выполнить в любом случае». Скрипт только читает
файлы и реестр, ничего не меняет и не отправляет наружу.

Что сканируется
---------------
Program Files, Program Files (x86), %LOCALAPPDATA%\Programs,
верхний уровень %LOCALAPPDATA% (глубина 7, тяжёлые каталоги
данных вроде Temp/Google/Microsoft пропускаются). Приложения из
нестандартных мест видны, только если запущены в момент прогона.
