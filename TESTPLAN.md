# Тест-план: JsAudit v1.1.0

## 1. Общие сведения

| | |
|---|---|
| Объект тестирования | портативная утилита аудита JS-движков (`JsAudit.ps1` + `JsAudit.cmd`) |
| Версия | v1.1.0 |
| Платформа | Windows 10/11 x64, встроенный PowerShell 5.1 |
| Тип тестирования | ручное функциональное по чек-листу + исследовательское (смоук на реальных машинах) |
| Автоматизация | не планируется: одноразовая портативная утилита без сборки и зависимостей; часть проверок покрывается смоук-прогонами |

## 2. Объём тестирования

**Внутри области:**
- запуск и портативность (двойной клик, read-only носитель, ключи командной строки);
- обход ExecutionPolicy и выбор 64-битного PowerShell лаунчером;
- сканирование файловой системы и классификация движков (Electron, CEF, WebView2, Chromium-embedded, Node, Deno, Bun, NW.js, Browser, системный JScript);
- срез живых процессов (в т.ч. разбор хостов `msedgewebview2.exe`, защита от переиспользования PID);
- генерация отчётов HTML (гистограммы без JS) / CSV / JSON (без BOM);
- поведение при повторных прогонах и отсутствие записи вне папки отчёта.

**Вне области:**
- нагрузочное тестирование на файловых массивах > 500 тыс. файлов;
- антивирусные эвристики сторонних продуктов (контролируется эмпирически, README содержит инструкцию для SmartScreen);
- Windows ниже 10, PowerShell 7+ (скрипт написан и закреплён под 5.1);
- корпоративные образы с программно заблокированным PowerShell (задокументированное ограничение).

## 4. Критерии

- **Вход:** исходники в `main`, смоук-прогон без ошибок в логе.
- **Выход:** все чек-пункты пройдены или осознанно отложены; критических дефектов нет; известные ограничения задокументированы в README и в отчёте утилиты.
