# JsAudit — аудит JS-движков на Windows

Портативная утилита (PowerShell), которая находит все приложения, внутри
которых исполняется JavaScript: **Electron, CEF, WebView2, вшитый Chromium,
Node.js, браузеры, системный JScript (WSH/MSHTA)**.

Отчёт — HTML-гистограмма + CSV + JSON. В самом отчёте ни одной строки
JavaScript: только HTML и CSS.

## Зачем

«Контролить весь JS в системе» на Windows нельзя одной кнопкой — движки
зашиты внутрь отдельных приложений. Первый шаг — карта: где JS вообще есть.
Эта утилита такую карту строит (для себя: узнал, что Telegram Desktop —
нативный и без JS, а мессенджер MAX хостит WebView2, т.е. контролируется
реестровыми политиками).

## Запуск

1. Скопировать папку (3 файла) на флешку или любой Windows 10/11.
2. Двойной клик по `JsAudit.cmd`.
3. Ждать 1–3 минуты — отчёт откроется в браузере сам.

Без установки и прав администратора. Используется встроенный PowerShell 5.1,
лаунчер сам обходит Execution Policy и берёт 64-битный PowerShell.

Отчёты падают в `out\` рядом со скриптом и подписаны именем машины и датой
(`js_audit_report_<PC>_<дата>.html`) — удобно гонять по нескольким ПК и
собирать отчёты в одну папку. Если носитель read-only — отчёт уходит в
`%TEMP%\JsAudit_<имя ПК>`.

```
JsAudit.cmd -NoOpen          не открывать браузер после прогона
JsAudit.cmd -OutDir "C:\R"   класть отчёты в указанную папку
```

Если SmartScreen ругается: «Подробнее» → «Выполнить в любом случае».
Скрипт только читает файлы и реестр, ничего не меняет и не отправляет наружу.

## Что ищет

| Маркер | Движок |
|---|---|
| `app.asar` | Electron (приложение целиком на JS) |
| `libcef.dll`, `cef.pak` | CEF (Chromium Embedded Framework) |
| `WebView2Loader.dll`, папка `EBWebView` | WebView2 (контролируется политиками) |
| `chrome_elf.dll` | вшитый Chromium |
| `node.exe` | Node.js |
| `wscript/cscript/mshta` | системный JScript |

Плюс срез живых процессов: кто прямо сейчас крутит JS (включая разбор,
какое приложение-хост стоит за процессами `msedgewebview2.exe`).

## Что сканируется

Program Files, Program Files (x86), `%LOCALAPPDATA%\Programs`, верхний
уровень `%LOCALAPPDATA%` (глубина 7; тяжёлые каталоги данных вроде
Temp/Google/Microsoft пропускаются). Приложения из нестандартных мест видны,
только если запущены в момент прогона (см. таблицу процессов в отчёте).

Ограничение: на жёстко залоченных корпоративных ПК PowerShell может быть
запрещён политиками — там не заведётся.
